\section{Datos de entrenamiento}

Para los datos de entrenamiento vamos a usar el conjunto de imágenes multi-etiqueta Corel-5k, que tiene 5000 imágenes de 50 categorías y un diccionario de 260 palabras o clases ~\url{https://www.kaggle.com/datasets/parhamsalar/corel5k}.

El dataset se compone de una carpeta con las 5000 imágenes y tres archivos csv que asignan las etiquetas a cada nombre de imagen. Lo primero que hacemos es componer tres DataFrame de Pandas, uno por cada archivo csv de manera que para cada elemento en la columna "\verb|image_name|" tiene las imágenes en formato PIL y en la columna "\verb|image_labels|" tiene una lista con el nombre de cada etiqueta de esa imagen. Luego los unimos en un único DataFrame ya que es más cómodo trabajar con todos los datos juntos.

Una vez tenemos un único DataFrame el siguiente paso es separarlo en dos de manera que tengamos dos conjuntos de datos con etiquetas diferentes, para ello primero contamos el número de etiquetas totales del dataset y lo ordenamos por las que más se repiten, en nuestro caso son "water" y "sky". Creamos un subconjunto de ejemplos que contienen la etiqueta "water" y eliminamos de ese subconjunto todas las etiquetas "sky", de esta manera conseguimos que la etiqueta "sky" sea exclusiva del segundo conjunto el cuál tendrá un procesado similar pero seleccionando los ejemplos que contengan "sky" y eliminando la etiqueta "water".

Ya hemos conseguido dos DataFrame que contienen clases exclusivas, en este paso vamos a convertirlos al tipo Dataset para seguir trabajando con ellos y dividir cada uno en dos subconjuntos "train" y "test" en una distribución de 80 y 20\%. Ahora tenemos un DataSet de imágenes y etiquetas en forma de palabras que vamos a cambiar para que sean números desde 0 hasta el número de etiquetas para el conjunto water y lo mismo para sky. Seleccionamos todas las etiquetas únicas de cada conjunto y las numeramos desde 0 hasta el tamaño del conjunto de etiquetas únicas -1 y luego aplicamos una transformación al DataSet para que intercambie cada etiqueta por su identificador.

Una vez tenemos el remapeo de etiquetas lo siguente es realizar transformaciones aleatorias sobre las imágenes para normalizarlas y para añadir varibilidad en el entrenamiento. Las operaciones que vamos a aplicar son reescalar a un tamaño de 32x32, volcado horizontal aleatorio, rotación aleatoria, recorte central, normalización y los conjuntos de etiquetas los vamos a poner en formato one-hot.

Por último vamos a configurar los DataLoaders que serán los conjuntos que se van a usar para el entrenamiento y la evaluación ajustando el formato para que tenga un diccionario con todas las imágenes en "\verb|image_name|" y todas las etiquetas en one-hot en "\verb|image_name|".

Con estos DataLoaders podemos empezar a trabajar.
